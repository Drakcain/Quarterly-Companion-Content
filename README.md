# Quarterly Companion — Content Repository

*Your Sunday School study companion.*

## Overview

This repository provides verified digital content for Quarterly Companion, a free, independently developed Android application designed to accompany the God's Acres Adult Sunday School quarterlies.

The available collection consists of:

- 35 Adult Sunday School quarterlies.
- 456 original lessons.
- Verified, application-compatible content packages.
- Preserved author, publisher, adaptation, and copyright notices.

## Content Integrity

Quarterly Companion independently verifies downloaded content against its trusted distribution metadata, including applicable manifests, SHA-256 checksums, package sizes, schemas, and original source identities.

Original lesson wording, Scripture references, lesson organization, and source-specific attribution are preserved.
